## Pourquoi montrer le produit (et pas juste l'ambiance)

Promethee peut se permettre de ne pas montrer le produit : personne n'achète immédiatement.
Ruby ne le peut pas. Dès l'arrivée, le visiteur doit comprendre **c'est quoi Ruby concrètement**.

→ D'où la vidéo dans le hero, et le principe « chaque section abstraite retombe sur un vrai bout de produit ».
